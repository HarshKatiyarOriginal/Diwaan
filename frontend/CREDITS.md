# Diwaan Frontend — Asset Credits

## 3D Seal (ThreeDiwaanSeal.jsx)
All 3D geometry is **procedurally generated** at runtime using Three.js built-in geometry classes (`IcosahedronGeometry`, `OctahedronGeometry`, `EdgesGeometry`, `BufferGeometry`). No external 3D model files are used.

Three.js is licensed under the [MIT License](https://github.com/mrdoob/three.js/blob/dev/LICENSE).
